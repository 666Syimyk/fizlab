# ФизЛаб 3D

Интерактивный курс физики: React/Vite, 62 темы, 620 задач и 3D-симуляции. Шесть демонстрационных тем открыты бесплатно; полный курс доступен с подпиской «ФизЛаб Плюс» на месяц или год. Android-покупки проводятся через Google Play / RevenueCat и подтверждаются сервером. Экран `/subscription` показывает реальные цены магазина, восстановление и управление подпиской. Без настроенных сервисов оплата недоступна и доступ не имитируется.

В личном кабинете — фото, учебный прогресс, подтверждение email и смена пароля. Регистрация проверяет пароль и его подтверждение; новый вход отзывает сессию предыдущего устройства. Восстановление по email проходит в три шага: почта аккаунта → проверка одноразового кода → новый пароль с подтверждением. Повторное письмо доступно через 2 минуты, код действует 15 минут и допускает пять попыток. После его проверки сервер выдаёт одноразовое разрешение на смену пароля на 10 минут; оно хранится только в памяти страницы, на сервере — его хеш. После смены пароля прежние сессии отзываются, пользователь входит с новым паролем. Отправка требует настроенного Resend; резервный код доступен как отдельный способ. Удаление аккаунта доступно в приложении и на `/account/delete`.

## Локальный запуск

Требуется Node.js 24 или новее: локальная база использует встроенный `node:sqlite`.

```powershell
npm ci
npm run build
npm run start:site
```

Откройте http://127.0.0.1:4174. База `data.local/fizlab.sqlite` создаётся автоматически и сохраняется между запусками. Для разработки отдельно запустите `npm run dev`: Vite проксирует `/api` на порт 4174.

```powershell
npm run test:server
npm run test:smoke
npm run lint
```

Полная проверка кода и изолированные браузерные сценарии:

```powershell
npx playwright install chromium
npm run typecheck
npm test
npm run test:e2e
npm run test:commerce
```

`test:e2e` запускает сервер на свободном порту с отдельной временной SQLite-базой и удаляет её после проверки. `test:smoke` использует уже запущенный сервер; для другой тестовой среды задайте `SMOKE_URL`. Браузерные сценарии создают и удаляют собственные тестовые аккаунты.

`test:commerce` запускает отдельный локальный Vite и проверяет экран подписок, сценарии покупки/восстановления и email-интерфейс с подменёнными API/магазином. Реальные письма, платежи и production-данные не используются; интеграцию с настоящим Google Play проверяйте отдельно через тестовый трек.

Полный аудит тем на 13 ширинах: `npm run audit:ui` (по умолчанию отдельный тестовый сервер на порту 4175). Параметры: `UI_BROWSER=firefox` / `webkit`, `UI_QUICK=1` для шести демонстрационных тем, `UI_TOPICS=dispersion,lenses` для выбранных тем, `UI_SHARD=0/3`, `1/3`, `2/3` для трёх независимых частей. JSON-отчёты и снимки сохраняются в `audit.local/`. Для других движков выполните `npx playwright install firefox webkit`. Используйте отдельную базу: в другом PowerShell задайте `$env:PORT='4175'`, `$env:FIZLAB_DB_PATH='audit.local/ui.sqlite'` и запустите `npm run start:site`.

GitHub Actions в `.github/workflows/checks.yml` выполняет установку, lint, строгую проверку TypeScript, тесты, production build, браузерные сценарии и проверку зависимостей.

## Android

Проект Capacitor находится в `android/`. Для выпуска нужен постоянный HTTPS API с той же реализацией Worker и D1. В PowerShell:

```powershell
$env:VITE_API_URL = 'https://your-domain.example/api'
npm run build:android
npm run android:open
```

Понадобятся Android Studio, Android SDK 36 и JDK 21. Установка приложения в Play Console — бесплатная; полный доступ продаётся через две подписки. Настройте Google Play, RevenueCat, подтверждённого отправителя писем и постоянный HTTPS backend, затем соберите подписанный Android App Bundle своим upload key. Временный Cloudflare Tunnel не подходит для выпуска.

Пошаговые настройки продуктов, ключей, подписи, тестирования и магазина: [docs/android-release.md](docs/android-release.md). Перед релизом выполните `npm run check:release`; проверка перечислит недостающие настройки без вывода секретов. Это не заменяет тестовую покупку через Play и проверку Google.

Развёртывание сервера, ограничения и шаги выпуска: [DEPLOY.md](DEPLOY.md).
