# Управление доступом

Суперадминистратор получает полный доступ к курсу и страницу `/admin`: список и поиск пользователей, количество аккаунтов и действующих ручных доступов, выдача и отзыв бесплатного доступа. Роль хранится на сервере отдельно от профиля и подписок Google Play.

Назначение существующего аккаунта в локальной SQLite-базе:

```powershell
node scripts/manage-admin.mjs grant --email owner@example.com
```

Отзыв роли:

```powershell
node scripts/manage-admin.mjs revoke --email owner@example.com
```

По умолчанию используется `data.local/fizlab.sqlite`; для другой базы укажите `--db PATH`. Команда не создаёт аккаунт и не меняет пароль, подтверждение почты или сессии. После назначения обновите страницу приложения. Вход осуществляется с обычным паролем этого аккаунта; восстановление — через `/recover`.

В панели можно задать обычному пользователю доступ на 30 или 365 дней с сегодняшнего дня. Новый срок заменяет прежний. Отзыв снимает только этот ручной доступ: оплаченная подписка продолжает действовать. Назначать других администраторов через панель нельзя. Платежи, пароли и удаление чужих аккаунтов в панели не доступны.

Сервер проверяет действующую сессию, устройство и роль при каждом запросе. Клиент повторяет проверку при возврате на страницу, восстановлении сети и раз в минуту; при ошибке, выходе из аккаунта и истечении срока доступ закрывается. Управление на сервере блокируется сразу после отзыва роли.

Проверки: `npm run test:admin`, `npm run test:account-access-client`, `node scripts/test-ui-admin.mjs` (изолированная среда с тестовыми аккаунтами).
