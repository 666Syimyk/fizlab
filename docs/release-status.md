# Состояние коммерческой версии — 30 сентября 2026

## Реализовано в проекте

- «ФизЛаб Плюс»: месячный и годовой планы, реальные локализованные цены Google Play, восстановление покупки и управление продлением. Бесплатными остаются шесть существующих демонстрационных тем.
- Официальный RevenueCat SDK; подписка проверяется сервером по UUID текущего аккаунта. Регистрация не выдаёт полный доступ. Учитываются истечение срока, отмена, возврат и grace period. Sandbox запрещён по умолчанию.
- Подтверждение email, восстановление по письму в три шага: почта → проверка кода → новый пароль с подтверждением. Повторная отправка через 120 секунд. Email-коды хранятся в виде HMAC, действуют 15 минут, имеют лимит пяти попыток. Проверка кода выдаёт отдельное одноразовое разрешение на 10 минут; после смены пароля прежние сеансы отзываются, автоматического входа нет. Резервный код остаётся отдельным способом. Действуют лимиты по IP и аккаунту.
- Удаление аккаунта вместе с учебными и авторизационными данными; надёжная очередь удаления профиля RevenueCat и компенсация запоздавшего запроса. Пользователь предупреждён, что удаление аккаунта не отменяет Google Play подписку.
- Страницы условий и конфиденциальности, инструкция выпуска, текст карточки магазина, проверка настроек релиза, Android signing через приватные настройки владельца.
- Исправлена ранняя потеря WebGL-контекста: обработчик устанавливается до запуска Three-сцены, сообщение о недоступности не теряется.

## Выполненные проверки

- `npm test` — прошёл: существующие и новые серверные/client тесты; отдельно проверены гонки удаления, смены пользователя и платежей.
- `npm run lint`, `npm run typecheck`, `npm run build` — прошли.
- `npm run test:e2e` — прошёл на production веб-сборке с временной SQLite: регистрация, резервное восстановление, кабинет, удаление, клавиатура, ошибки загрузки/WebGL, мобильные размеры и доступность.
- `npm run test:commerce` — прошёл: 5 браузерных состояний подписки, 7 имитированных native-покупок/восстановлений, 10 email-сценариев, включая отдельную проверку кода, таймер повторной отправки, очистку при смене почты, истёкшее разрешение и мобильные экраны. Почтовые и платёжные вызовы подменены тестовыми ответами; это не реальные транзакции.
- `npm audit --audit-level=moderate` — найдено 0 уязвимостей.
- Android debug-сборка с JDK 21/SDK 36 — прошла после повтора оборвавшейся загрузки Google Maven. Подтверждён Google Play Billing 8.3.0. Debug APK не является подписанным релизным AAB; без production API он не подтверждает работу аккаунтов на устройстве.

Существующая проверка контента сообщает восемь редакционных/медиа-замечаний (различия заголовков и недостающие портреты); они не мешают сборке. Vite предупреждает о крупных 3D-бандлах; производительность и стабильность надо проверить на реальных Android-устройствах.

## До продаж и публикации

1. Уточнить рынок и цены. Стартовое предложение для Казахстана: 1 490 ₸/месяц, 9 990 ₸/год. В магазине цены пока не созданы.
2. Подготовить Play Console, верификацию владельца, платёжный профиль, продукт `fizlab_pro` и base plans `monthly` / `annual`.
3. Настроить RevenueCat, серверный секрет и публичный Android SDK key, Current Offering, entitlement и RTDN. Отдельно проверить правила восстановления за исходным аккаунтом.
4. Развернуть постоянный HTTPS backend с постоянной базой и почтовым отправителем Resend на подтверждённом домене. Секреты хранить на сервере.
5. Указать настоящие `VITE_SUPPORT_EMAIL`, `VITE_DEVELOPER_NAME`, публичные URL условий, конфиденциальности и удаления. `npm run check:release` сейчас ожидаемо сообщает об отсутствующих публичных настройках.
6. Финализировать иконку и графику карточки, снять скриншоты из реальной Android-сборки, заполнить Data safety, аудиторию, рейтинг и инструкции для ревьюеров.
7. Проверить на устройстве реальные тестовые месячную/годовую покупки, pending, отмену, возврат, восстановление и доставку писем. При необходимости выполнить требования закрытого тестирования Play.
8. Собрать AAB с upload key владельца и отправить через его Play Console. Приложение в Google Play пока не опубликовано.

Подробные шаги и официальные источники: [Android release](android-release.md), [развёртывание](../DEPLOY.md), [карточка магазина](play-listing-ru.md).

## Ограничение защиты материалов

Доступ контролируется подпиской в приложении, но материалы включены в JS/Android assets. Это не DRM: модифицированный клиент может извлечь содержимое. Если нужна защита от извлечения, до публичных продаж следует отдельно реализовать авторизованную серверную доставку платных материалов и проверить Play Integrity.
